## 二、刚查到的 Prism 真相（我之前判断错了）

我之前说「Prism 是 Windows 程序」，**错了**。实际情况：

```
你的 Downloads 里就有：prism-v1.0.5-beta.7(1).apk   40MB
包名：com.prismtool.box
```

拆开看：

| 部件 | 说明 |
|---|---|
| `classes.dex` (3.7MB) | Kotlin 写的安卓壳 |
| `lib/arm64-v8a/libprism.so` (37MB) | **Go 1.26 编译的核心引擎** |
| WebView | 界面就是加载 `http://127.0.0.1:8080/` |

**本机 API（从壳里扒出来的真实清单）**：

```
/api/bot/status      机器人状态
/api/config          配置
/api/ai/chat         AI 对话（AI帮写就走这个）
/api/push/pending    拉待办指令   ← 它自己就有指令队列
/api/push/ack        确认指令
/api/task/list       任务列表
/api/task/stop       停任务
/draw  /piano        内置小工具
ws://127.0.0.1:8080/ws   WebSocket 长连接
```

**保活机制**（这就是你说的"内容要能保留"）：

```
com.prismtool.box.KeepService           前台服务（specialUse）常驻
com.prismtool.box.FloatingWindowService 悬浮窗
权限：开机自启 / 忽略电池优化 / 悬浮窗 / Shizuku API_V23
```

**所以：端口确实是 8080，但 Prism 是安卓应用，装在云手机里。**
我们的被控端也做成 APK，和它装同一台云手机，走 127.0.0.1:8080 —— 这条路是对的。

### `prism_tool` 能调什么（这就是"改底层"）

从 Prism 提示词里提取出的 29 个真实工具，里面有：

```
write_plugin_file      改写插件文件  ← 改底层
lua_call               执行 Lua
game_call              游戏内调用
call_plugin_function   调插件函数
system_shell           跑 shell 命令【高危】
read_file/write_file/edit_lines/list_dir   读写文件
listen_packet/send_packet/query_packets    抓包发包
send_command_wait_output                   发指令等输出
```

**所以你说的"甚至要改写它的底层代码"——不用改，直接调就行。**
你的 AI Agent 拿到网址，就能用 `write_plugin_file` 往 Prism 里写插件。

⚠️ `system_shell` 等于把云主机的 shell 交给 AI。我在工具描述里加了警告，
但没做拦截——你要的就是更大权限。密钥别外泄。
