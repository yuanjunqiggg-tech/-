### 3.5 `POST /api/ai/chat` ✅ ★★ 核心实测成功

**请求：**
```json
{
  "model_name": "prism自动",
  "plugin_id": "",
  "mode": "",
  "session_name": "test-001",
  "messages": [{ "role": "user", "content": "请回复四个字：测试成功" }]
}
```

**响应（SSE 流）：**
```
event: ai_thinking
data: {"text":"The"}

event: ai_thinking
data: {"text":" user asks"}

... (思考过程流式输出)

event: ai_chunk
data: {"text":"测试成功"}

event: ai_usage
data: {"input":7260,"output":116}

event: ai_done
data: {"done":true}
```

**关键数据：**
- ✅ `ai_thinking` 事件真实推送（AI 思考过程）
- ✅ `ai_chunk` 事件真实推送（正文）
- ✅ `ai_usage` 返回 **input: 7260 / output: 116**
- ✅ `ai_done` 正常结束

> 💡 **`input: 7260` tokens** 说明系统提示词极长（约 7000+ tokens）。
> 这正是用户想「分出来」的核心内容 —— 但它**不在请求的 messages 里**，
> 而是 Prism 服务端拼装的。

## 四、发现的问题与对策

### 问题 1：系统提示词看不到

`ai_usage` 显示 input 7260 tokens，但我们只发了 1 条短消息。
说明 **7000+ tokens 是 Prism 在服务端拼装的**，客户端拿不到。

**对策（两种）：**

**方案 A：网关侧透明代理（简单）**
把 Prism 的模型 BaseURL 从 `https://prism.adblanlu.qzz.io/api/prism/ai`
改成指向我们的网关。这样所有请求都经过我们，能看到**最终发给模型的完整 prompt**。

```
Prism → 我们的网关 → prism.adblanlu.qzz.io
         ↑ 在这里记录完整 prompt
```

**方案 B：改 hosts / 中间人（不推荐）**
拦截 `prism.adblanlu.qzz.io` 流量。需要证书，复杂且脆弱。

**推荐方案 A** —— 只需在 Prism 界面「模型设置」里改一下 BaseURL。

### 问题 2：本机代理干扰

访问 127.0.0.1 必须绕过代理。在代码里应显式设置：

```js
// Workers 无此问题（云端），但本机脚本要注意
process.env.NO_PROXY = 'localhost,127.0.0.1'
```

### 问题 3：会话不落盘到文件

`luanlu/ai_sessions/` 一直是空的，会话存在 `td_state.db`（自定义格式）。
说明 **Prism 自己不提供会话文件读取**，我们只能靠自己旁路记录。
→ 这印证了网关方案的必要性。

## 五、修正后的架构（推荐）

```
┌──────────────────────┐
│  手机 APK / 电脑网页   │
└───────────┬──────────┘
            │ HTTPS
┌───────────▼────────────────────────┐
│  ai-api.youyuanqi.dpdns.org        │
│  Cloudflare Workers 网关            │
│  · 鉴权 / 提示词编辑 / 用量统计      │
└───────────┬────────────────────────┘
            │ Tunnel
┌───────────▼────────────────────────┐
│  prism.youyuanqi.dpdns.org :8080   │
│  → 本机 Prism                      │
└───────────┬────────────────────────┘
            │ ★ Prism 的模型 BaseURL 改指向 ↓
┌───────────▼────────────────────────┐
│  prompt-capture.youyuanqi.dpdns.org│
│  提示词捕获代理（透明转发）          │
│  · 记录最终完整 prompt → D1         │
└───────────┬────────────────────────┘
            │
┌───────────▼────────────────────────┐
│  prism.adblanlu.qzz.io/api/prism/ai│
│  （Prism 官方 AI 中转）             │
└────────────────────────────────────┘
```

这个架构能**同时实现**：
1. 远程操控（经 Workers → Tunnel → Prism）
2. 提示词完整捕获（经捕获代理 → 官方中转）
3. 提示词可编辑（在捕获代理里替换）
