## 一、这套东西是干什么的

把 Prism 工具箱里的「AI帮写」搬到外部，让你**用手机或电脑远程操控它**。

```
┌──────────────┐         ┌─────────────────┐         ┌──────────────┐
│  控制端       │  HTTPS  │  Cloudflare      │  长轮询  │  被控端       │
│  网页 / APK   │ ──────► │  Worker + D1     │ ◄────── │  安卓云手机   │
│              │         │  ai-api.xxx      │         │  APK         │
└──────────────┘         └─────────────────┘         └──────┬───────┘
                                                             │ HTTP
                                                             ▼
                                                      ┌──────────────┐
                                                      │ 本机 Prism    │
                                                      │ :8080        │
                                                      └──────────────┘
```

**关键设计**：被控端**主动拨出**到云端（长轮询），所以
- 云手机不需要公网 IP、不需要 root、不需要装 cloudflared
- 天然穿透 NAT
- 支持多台设备同时在线

已经编译好并验证过，统一放在 **`apk/dist/`** 里，直接取用：

| 文件 | 装在哪 | 包名 | 应用名 | 大小 |
|------|--------|------|--------|------|

```
ds-platform-ai-assist/apk/dist/
├── Prism被控端-v1.0.apk   ← 装云手机（跑 Prism 的那台）
└── Prism控制台-v1.0.apk   ← 装你日常用的手机（可选，网页版已经够用）
```

原始构建产物路径（一般不用管）：
```
apk/agent-app/android/app/build/outputs/apk/debug/app-debug.apk
apk/console-app/android/app/build/outputs/apk/debug/app-debug.apk
```

> **控制端 APK 为什么是「壳」？**
> 控制台 HTML 里内联了访问密钥。把它打进 APK 再提交到 git 等于泄露密钥，
> 所以控制端改成直接加载已上线的 https://prism-console-7v1.pages.dev/ 。
> 好处是永远同步最新版本，坏处是需要联网（控制台本来就需要联网）。

### 被控端安装（云手机）

### 安装步骤

1. **传到云手机**
   - 方式一：云手机里直接用浏览器下载这个 APK
   - 方式二：`adb connect <云手机IP>:<端口>` 然后 `adb install -r app-debug.apk`
   - 方式三：把 APK 上传到网盘，在云手机里下载安装

2. **打开 App，填三样东西**
   | 字段 | 填什么 |
   |------|--------|
   | 网关地址 | `https://ai-api.youyuanqi.dpdns.org` |
   | 访问密钥 | 上面那个密钥 |
   | 设备名称 | 随便起，比如「云手机1号」 |

   然后点「绑定设备」。

3. **安装后必做三件事**（不做会掉线）
   - ✅ **授予通知权限**（Android 13+ 必须有，否则前台服务起不来）
   - ✅ **电池优化设为「无限制」** —— App 里有「去设置」按钮直接跳转
   - ✅ **允许自启动** —— App 里有「去设置」按钮
   - ✅ 云手机平台自己的「后台保活」开关（红手指/多多云都有），**务必打开**

4. **确认在线**
   回到控制台 https://prism-console-7v1.pages.dev/ ，左侧设备列表里应该能看到这台设备。

### 控制端安装（你自己的手机，可选）

装 `Prism控制台-v1.0.apk` 即可，打开直接就是控制台界面，**不用填任何东西**。

不装也完全没问题 —— 手机浏览器打开 https://prism-console-7v1.pages.dev/ 效果一样。

## 五、怎么用

### 对话

在控制台选中设备 → 底部输入框打字 → 回车。
AI 的回复会**流式**显示（一个字一个字冒出来），跟你直接开 Prism 一样。

### 调用工具

控制台可以列 Prism 的所有工具（`list_plugins`、`list_skills`、`list_packets`、
`packet_stats`、`shizuku_status`、`wait_packet`、`send_packet` 等），
点一下就能在云手机上执行。

### 抓包

- **实时订阅**：下发 `packet_sub` 指令，指定时长（最长 60 秒）和协议类型
- **历史回看**：控制台「抓包」页，所有抓到的包都落库了，可以随时翻

### AI Agent（Codex）直接接

MCP 服务器已经写好，在 `mcp/` 目录。配置后 Codex 可以直接操作这套系统。

## 九、常用命令速查

```bash
# 跑端到端回归测试（云端）
cd ds-platform-ai-assist
python tools/e2e_test.py --base https://ai-api.youyuanqi.dpdns.org/api/v1 --key <密钥>

# 重新部署控制台
python tools/build_console.py --endpoint https://ai-api.youyuanqi.dpdns.org --key <密钥> --out .pages_dist
cd workers && npx wrangler pages deploy ../.pages_dist --project-name=prism-console --branch=main

# 重新编译被控端 APK
cd apk/agent-app && npx cap sync android
cd android && ./gradlew.bat assembleDebug

# 本地起被控端（联调用）
python agent/prism_agent.py --name "测试设备"
```
