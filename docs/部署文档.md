### 第 1 步：安装 wrangler

打开终端（PowerShell 或 CMD）：

```bash
cd "C:\Users\16650\WorkBuddy AI\2026-09-13-00-20-42\ds-platform-ai-assist\workers"
```

`wrangler login` 会打开浏览器，点「允许」即可。

1. 双击启动 **Prism 工具箱**
2. 观察它的窗口或控制台，会显示：

3. **记下这个 `XXXXX`**，后面要用

> 如果没看到这行字：Prism 启动后一般会自动打开浏览器窗口，

## 阶段 2：部署 Workers 网关

### 2.1 修改配置

打开 `workers/wrangler.toml`，确认：

```toml
[vars]
PRISM_TUNNEL_URL = "https://prism.youyuanqi.dpdns.org"   # ← 用 prism 子域
PLATFORM_ACCESS_KEY = "你的强密码"                        # ← 改掉默认值
```

### 2.2 设置密钥（推荐，比写在 toml 里安全）

```bash
npx wrangler secret put PLATFORM_ACCESS_KEY
# 输入你的密钥，回车
```

### 2.3 部署

```bash
npm run deploy
```

成功后终端会输出：
```
Published ds-platform-ai-assist
  https://ds-platform-ai-assist.xxx.workers.dev
```

### 2.4 绑定自定义域名

**方式 A（已写在 wrangler.toml 里，自动绑定）**

本配置用的是 `ai-api.youyuanqi.dpdns.org`。

**方式 B（手动，Cloudflare Dashboard）**

1. 打开 https://dash.cloudflare.com
2. 左侧 **Workers & Pages** → 点 `ds-platform-ai-assist`
3. 顶部 **Settings** → **Domains & Routes**
4. 点 **Add** → **Custom Domain**
5. 填入 `ai-api.youyuanqi.dpdns.org` → **Add Domain**
6. 等待状态变成 **Active**（约 1-2 分钟）

> ⚠️ 如果 `api.youyuanqi.dpdns.org` 已被你之前的 worker 占用，
> 就用 `ai-api` 子域，避免冲突。

### 2.5 验证部署

```bash
curl https://ai-api.youyuanqi.dpdns.org/health
```

预期返回：
```json
{
  "ok": true,
  "data": {
    "gateway": "online",
    "prism_online": false,
    "prism_error": "..."
  }
}
```

`prism_online: false` 是正常的 —— 因为隧道还没配（下一阶段）。
关键是 **`gateway: online`** 说明网关跑起来了。

## 阶段 3：配置 Tunnel 暴露 Prism

### 3.1 编辑 tunnel 配置

打开 `tunnel/config.yml`，把 `<PRISM_PORT>` **全部替换**成你记下的端口号。

例如端口是 `5000`，就把所有 `localhost:<PRISM_PORT>` 改成 `localhost:5000`。

> 💡 快速替换（PowerShell）：
> ```powershell
> (Get-Content tunnel\config.yml) -replace '<PRISM_PORT>','5000' | Set-Content tunnel\config.yml
> ```

### 3.2 在 Cloudflare 添加 DNS 记录

1. 打开 https://dash.cloudflare.com
2. 选择域名 `youyuanqi.dpdns.org`
3. 左侧 **DNS** → **Records** → **Add record**
4. 填写：

   | 字段 | 值 |
   |---|---|
   | Type | `CNAME` |
   | Name | `prism` |
   | Target | `9648bb44-14b6-493c-81d2-e0fae070d95a.cfargotunnel.com` |
   | Proxy status | **Proxied**（橙色云朵） |

5. **Save**

### 3.3 启动隧道

**方式 A：用配置文件（推荐）**

```bash
cloudflared tunnel --config "C:\Users\16650\WorkBuddy AI\2026-09-13-00-20-42\ds-platform-ai-assist\tunnel\config.yml" run
```

**方式 B：用你原有的配置**

把你原有的 `config.yml`（在 `ds-platform/` 里的那份）
按 `tunnel/config.yml` 的 `prism.youyuanqi.dpdns.org` 段落照抄新增，然后：

```bash
cloudflared tunnel --config <你原有配置路径> run
```

> 💡 想后台常驻，可注册为 Windows 服务：
> ```bash
> cloudflared service install
> ```

### 3.4 验证隧道

```bash
curl https://prism.youyuanqi.dpdns.org/api/config
```

如果返回 JSON（不是 502/404），说明 **隧道通了**。

再用网关的健康检查确认端到端：

```bash
curl https://ai-api.youyuanqi.dpdns.org/health
```

这次 `prism_online` 应该变成 `true`。

## 阶段 4：验证全链路

### 4.1 测试 AI 对话接口

```bash
curl -X POST https://ai-api.youyuanqi.dpdns.org/api/v1/ai-assist/chat \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer 你的密钥" \
  -d '{
    "model_name": "你的模型名",
    "plugin_id": "ds_ai_agent",
    "session_name": "test-001",
    "messages": [
      {"role": "user", "content": "你好，请介绍一下你自己"}
    ]
  }'
```

预期：返回 **SSE 流**（`data: {"event":"ai_chunk",...}` 逐块出现）。

### 4.2 确认提示词已捕获

```bash
curl -H "Authorization: Bearer 你的密钥" \
  https://ai-api.youyuanqi.dpdns.org/api/v1/ai-assist/prompts
```

应该能看到刚捕获到的系统提示词（带 `preview` 字段）。

### 4.3 查看消息全文

```bash
curl -H "Authorization: Bearer 你的密钥" \
  https://ai-api.youyuanqi.dpdns.org/api/v1/ai-assist/sessions/test-001/messages
```

这里是**完整的对话记录**，包括那条被标记 `is_system_prompt: 1` 的提示词。

**到这一步，"把提示词分出来" 就实现了。**

### 4.4 测试提示词替换

```bash
# 1. 把抓到的提示词转成模板
curl -X POST https://ai-api.youyuanqi.dpdns.org/api/v1/ai-assist/templates/promote \
  -H "Authorization: Bearer 你的密钥" \
  -H "Content-Type: application/json" \
  -d '{"capture_id": 1}'

# 2. 编辑并启用模板
curl -X POST https://ai-api.youyuanqi.dpdns.org/api/v1/ai-assist/templates \
  -H "Authorization: Bearer 你的密钥" \
  -H "Content-Type: application/json" \
  -d '{
    "id": 1,
    "name": "我的提示词",
    "content": "你是我的专属助手……（这里写你的版本）",
    "scope": "plugin",
    "plugin_id": "ds_ai_agent",
    "enabled": true,
    "priority": 10
  }'
```

之后所有请求都会用**你写的提示词**发给 Prism，而不是它本地的版本。

## 阶段 6：手机 APK 集成

APK 直接加载网页控制台地址即可（Capacitor 的 `server.url` 指向 `https://ai.youyuanqi.dpdns.org`），
无需重新打包前端资源。

参考你现有的 `ds-platform/mobile/capacitor.config.ts`：

```ts
server: {
  url: 'https://ai.youyuanqi.dpdns.org',
  cleartext: false,
  androidScheme: 'https',
}
```

然后：

```bash
cd ds-platform/mobile
npx cap sync android
cd android && ./gradlew assembleDebug
```

## 附录：接口速查

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/health` | 健康检查（含 Prism 在线状态） |
| POST | `/api/v1/ai-assist/chat` | **AI 对话（SSE）** |
| GET | `/api/v1/ai-assist/sessions` | 会话列表 |
| GET | `/api/v1/ai-assist/sessions/:id/messages` | 会话完整消息 |
| GET | `/api/v1/ai-assist/prompts` | **捕获的提示词列表** |
| GET | `/api/v1/ai-assist/prompts/:id` | **提示词全文** |
| GET | `/api/v1/ai-assist/templates` | 提示词模板列表 |
| POST | `/api/v1/ai-assist/templates` | 新建/更新模板 |
| DELETE | `/api/v1/ai-assist/templates/:id` | 删除模板 |
| POST | `/api/v1/ai-assist/templates/promote` | 抓取→模板 |
| GET | `/api/v1/ai-assist/stats` | 统计概览 |

所有接口（除 `/health`）都需要请求头：
```
Authorization: Bearer <PLATFORM_ACCESS_KEY>
```

## 常见问题

### Q1: `/health` 显示 `prism_online: false`

排查顺序：
1. Prism 是否在运行？
2. 端口是否填对？`curl http://127.0.0.1:<PRISM_PORT>/` 本机能通吗？
3. DNS 记录加了吗？`nslookup prism.youyuanqi.dpdns.org`
4. 隧道进程在跑吗？

### Q2: SSE 流式变成一次性返回

Tunnel 的 `disableChunkedEncoding` 必须是 `false`（本配置已设）。
另外 Cloudflare Dashboard → 域名 → **Network** → 关闭 **Rocket Loader**。

### Q3: 返回 401

密钥没配对。检查 `wrangler secret put` 设置的值，
和请求头 `Authorization: Bearer xxx` 是否一致。

### Q4: Prism 端口每次启动都变

Prism 是动态分配端口的。解决方案：
- 每次启动后更新 `tunnel/config.yml` 并重启隧道（麻烦）
- **或**：用固定端口启动（如果 Prism 支持 `--port` 参数）
- **或**：写个脚本自动读取端口并生成配置（我可以帮你做）

### Q5: 提示词没被抓到

Prism 通过 SSE 返回，系统提示词可能在**服务端拼装**，
不在 `messages` 里。这种情况下网关看不到原始提示词。

**备选方案**：用代理模式，把 Prism 的上游模型地址
（在 Prism「模型设置」里的 BaseURL）改成指向你的网关，
这样你就能看到**最终发给模型的完整请求**。
