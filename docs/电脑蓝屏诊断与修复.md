## 五、修复方案

### 第 1 步：确诊是哪一根内存条坏了（必做）

**这是唯一能根治的办法，必须物理操作。**

#### 先说结论：软件定位不到是哪一根

我解析了这台机器的 SMBIOS 原始表，结果是：

```
Bottom-Slot 1 (left)   8GB  → 物理地址 0~8GB，交错位置 1
Bottom-Slot 2 (right)  8GB  → 物理地址 0~8GB，交错位置 2
                              ↑ 两根映射到同一段区间
```

**双通道交错（2-way interleave）模式**：物理地址在两根条子之间交替分布，
所以蓝屏报告里的出错地址**反推不出**落在哪一根上。
这是内存控制器的工作方式决定的，不是工具不够好 —— 任何软件都做不到。

> 想自己复现这条结论，跑：
> `powershell -ExecutionPolicy Bypass -File tools\locate_bad_ram.ps1`

#### 所以最快的办法是「单条测试」

**不要**一上来就跑满 MemTest86 两轮（16GB 要 4–8 小时）。
拆成单条后，8GB 跑一轮只要约 10 分钟：

```
① 关机断电、拔电池排线、摸金属放静电，拆后盖
② 拔掉一根（建议先拔右侧 Bottom-Slot 2，多数机型这根更好拆）
③ 只留一根开机，跑 MemTest86 至少 2 轮（约 20 分钟）
   ├─ 无报错 → 拔下来那根是好的，坏的是现在插着的这根
   └─ 有报错 → 现在插着的这根就是坏的
④ 换上好的那根，机器照常用（8GB 够日常）
⑤ 买同规格的补上即可
```

**要买的规格**（两根完全一样，很好配）：
`DDR4-3200 SODIMM（笔记本长条）`，原型号 `SK Hynix HMA81GS6CJR8N-XN`，
买同规格任意品牌都行（金士顿/威刚/三星均可），一根 8GB 约几十块。
想顺便升级的话，直接买 2×16GB 换掉，注意必须是 **SODIMM** 不是台式机的长条。

> ⚠️ 拆机前务必断电、拔电池排线、放静电。
> 手生的话找维修店帮忙测，一般几十块，别硬掰。

### 第 2 步：临时缓解（换内存前的过渡）

下面的脚本会把系统调到「**低内存占用、崩溃后快速恢复**」的状态：

| 措施 | 作用 |
|------|------|
| 关闭快速启动 | 避免休眠文件里残留损坏的内核状态，减少启动即崩 |
| 缩小崩溃转储 | 现在每次崩要写 2.4GB 转储（耗时且写盘压力大），改成小转储 → 重启更快 |
| 关闭内存压缩 | 减少对已损坏内存页的读写频率 |
| 保持虚拟内存托管 | 保证有足够交换空间，降低 0x154 概率 |

运行方式（**需要管理员权限**）：

```powershell
# 右键「Windows PowerShell」→ 以管理员身份运行 → 粘贴：
powershell -ExecutionPolicy Bypass -File "C:\Users\16650\WorkBuddy AI\2026-09-13-00-20-42\ds-platform-ai-assist\tools\fix_crash_mitigations.ps1"
```

### 第 3 步：其他建议

- **检查 BIOS 更新**：当前 F.43 是 2022 年的。
  到 https://support.hp.com 搜 `15-dk1xxx` 看有没有新版（新版有时会修内存时序问题）
- **清洁散热**：游戏本积灰后 CPU 降频、供电波动也会诱发内存错误。两年以上的机器建议清灰换硅脂
- **插电使用**：电池老化导致供电不稳时，也会影响内存。尽量插电
- **别再跑高内存负载任务**：编译、虚拟机、多开浏览器最吃内存，也最容易命中坏页
