# 「APK 自己打开」和「8080 接口」是同一回事

> 结论先给：**能做到，而且本来就是一回事。**
> 下面全是拆包拿到的证据，不是推断。

---

## 一、证据

把 `prism-v1.0.5-beta.7(1).apk` 拆开看：

| 证据 | 说明 |
|---|---|
| APK 里 `assets/` 只有一张 `logo.png`，**没有任何前端页面** | 界面不是打包进去的 |
| `classes.dex` 里硬编码字符串 `http://127.0.0.1:8080` | Kotlin 壳就指这个地址 |
| `MainActivity` 是个 WebView，加载 `http://127.0.0.1:8080/` | 你在 APK 里看到的每一个页面都是它 |
| `lib/arm64-v8a/libprism.so` 37MB，**Go 1.26.0** | 真正的引擎，和 APK 同进程 |
| 界面里每个按钮都是 `A('POST','/api/xxx', ...)` | 就是往 8080 发 HTTP |

**所以：你在 APK 里点按钮 = 向 127.0.0.1:8080 发请求。**
不存在「两条路、两套数据」。

---

## 二、数据到底存在哪

不是存在网页里，是存在 Go 引擎落在磁盘上的文件里：

```
/data/data/com.prismtool.box/files/     ← config.json、td_state.db（bbolt）
/sdcard/Download/Prism                  ← 导出产物
WebView localStorage                    ← prism_token、主题、向导状态
```

AI帮写 的对话另有专门的持久化接口：

```
GET    /api/ai/sessions?plugin_id=xxx          列出会话
GET    /api/ai/sessions/recent?plugin_id=xxx   最近会话
POST   /api/ai/sessions                        保存会话 {name, plugin_id, messages}
POST   /api/ai/sessions/load                   读取会话
POST   /api/ai/sessions/rename                 改名
DELETE /api/ai/sessions                        删除
```

**这部分跟「界面开没开」完全无关**，只要进程活着它就在；
你在 APK 里打开 AI帮写 → 会话列表，能看到和 API 写进去的是同一份。

你遇到的「每次点进去都重新加载」，原因是 **Prism 进程被云手机回收了**，
引擎重启 → 内存态没了、8080 也没了 → 界面只能重新拉。
**不是 8080 这个通道本身有毛病。**

---

## 三、所以唯一的前提是：Prism 进程得活着

Prism 自己已经在做保活：

- `KeepService` 前台服务（`foregroundServiceType=0x40000000` specialUse）
- `FloatingWindowService` 悬浮窗
- `BootReceiver` 开机自启
- 申请忽略电池优化
- Shizuku `API_V23`

我已经在这之上加了一层 **被控端兜底**（v1.1）：

```
每条指令执行前
  → 探测 http://127.0.0.1:8080/api/bot/status（1.5s 超时）
  → 没响应 → 用显式 Intent 拉起 com.prismtool.box/.MainActivity
            （失败再试 getLaunchIntentForPackage，再试 KeepService）
  → 轮询等待最多 25s，直到 8080 有响应
  → 才真正执行指令
```

也就是说：**Prism 被杀了，下一条指令自己会把它救回来**，不用人去点。

另外发现 `com.prismtool.box.PrismDataProvider`（exported=true，
`DOCUMENTS_PROVIDER`）—— 这是**不改 Prism 代码**也能从外部读它持久化文件的
正规口子，需要时可以用 SAF 去挂。

```
https://ai-api.youyuanqi.dpdns.org/mcp?key=5dc5ad37...ff71791
```

- 密钥**已经嵌在网址里**，AI Agent 只要这一个 URL，不用再配 key、不用再填 API

## 五、还没验证的部分（不吹）

- 所有 e2e（relay 11/11、MCP 20/20、真 exe 7/7、控制台 SSE 7/7）
  都是拿 `tools/fake_prism.py` 跑的，**没跑过真 Prism**
- 真机拉起 Prism 的 Intent 在云手机上是否放行，要装上去才知道
  （Android 12+ 后台启动 Activity 有限制，代码里三级降级 + 全 catch）
- `/api/ai/sessions` 的字段细节是从 JS 片段和 Go struct 反推的，
  真机上如果字段名有出入，看返回的 error 调一下即可
