# ============================================================
# Prism 控制端 App（手机）
#
# 这个 App 装在你自己的手机上，用来远程查看云手机的 AI 反馈、
# 下指令、抓包。界面就是 web/console.html，套个原生壳。
#
# 构建方式：Capacitor（和被控端同一套工具链）
# ============================================================

## 一、为什么不用纯网页

`web/console.html` 用手机浏览器打开就能用，功能完全一样。
打包成 APK 的三个额外好处：

1. **离线壳**：界面本身不需要联网加载，秒开
2. **推送通知**（可选）：指令完成时能收到系统通知
3. **图标 / 全屏**：体验更像一个正经 App

如果你只想快速用起来，**直接手机浏览器打开网关地址就行**，跳过下面全部步骤。

---

## 二、构建步骤

```bash
cd ds-platform-ai-assist/apk
mkdir -p console-app && cd console-app

npm init -y
npm i @capacitor/core@6 @capacitor/cli@6 @capacitor/android@6
npx cap init "Prism 控制台" com.prism.console --web-dir=www

mkdir -p www
cp ../../web/console.html www/index.html

npx cap add android
npx cap sync android
```

### 部署 web 资源（把 console.html 传到云端）
控制端 APK 也可以直接从云端加载界面，这样改界面不用重新打包：
```bash
# 用 wrangler 把 web/ 目录作为静态资源部署
cd ../../workers
wrangler pages deploy ../web --project-name=prism-console
```

## 三、App 配置

### 1. 允许明文 HTTP（本地调试用）
生产环境走 HTTPS，不需要这个。

### 2. 全屏 / 状态栏颜色
`android/app/src/main/res/values/styles.xml`：
```xml
<style name="AppTheme.NoActionBar" parent="Theme.AppCompat.DayNight.NoActionBar">
    <item name="android:statusBarColor">#ffffff</item>
    <item name="android:windowLightStatusBar">true</item>
</style>
```

### 3. 应用图标
把图标放到 `android/app/src/main/res/mipmap-*/ic_launcher.png`
（各尺寸：48/72/96/144/192 px）

### 4. 允许混合内容（调试本地网关时）
`android/app/src/main/AndroidManifest.xml` 里 `<application>` 加：
```xml
android:usesCleartextTraffic="true"
```
**注意**：正式使用请去掉，走 HTTPS 更安全。

---

## 四、构建

```bash
npx cap sync android
cd android

# Debug 版（自己用，直接装）
./gradlew assembleDebug
# 产物：android/app/build/outputs/apk/debug/app-debug.apk

# Release 版（分发用，需签名）
./gradlew assembleRelease
```

签名步骤与被控端相同，见 `被控端构建说明.md` 第五节。

---

## 五、安装使用

```bash
adb install -r app-debug.apk
```

首次打开会让你填：
1. **网关地址**：`https://ai-api.youyuanqi.dpdns.org`
2. **访问密钥**：部署 Workers 时设的 `PLATFORM_ACCESS_KEY`

填完点「保存并连接」，就能看到云手机设备列表了。

## 六、常见问题

**Q: 一直提示「加载失败」**
- 密钥填错了（部署 Workers 时设的那个）
- 网关地址多了斜杠或少了 `https://`
- 手机上能不能打开 `https://你的网关/health`？打不开就是网络问题

**Q: 看不到设备**
- 云手机上的被控端没绑定成功
- 云手机被控端不在线（去「信息」页看在线状态）
- 点右上角「刷新」

**Q: 下发指令后没反应**
- 设备离线（指令会排队，等设备上线后自动执行）
- 设备在线但 Prism 没启动（去信息页看「Prism 运行中」）

---

## 七、备选：不打包，直接网页

如果你不想折腾 Android SDK，直接用手机浏览器：

1. 打开 `https://ai-api.youyuanqi.dpdns.org/console.html`
2. 填密钥
3. 加书签，或者「添加到主屏幕」当 PWA 用

功能完全一致，只是没有系统通知。**推荐先用这个验证整条链路通不通，再决定要不要打包。**
