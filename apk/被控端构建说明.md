# ============================================================
# Prism 被控端 App · 云手机（Android）
#
# 这个 App 跑在云手机上，职责：
#   1. 提供界面：填网关地址/密钥、绑定设备、看日志、看在线状态
#   2. 后台常驻：前台服务 + 开机自启，保证不掉线
#   3. 执行引擎：长轮询领指令 → 调本机 Prism → 上报结果
#
# 构建方式：Capacitor（把 Web 界面套进原生壳，同时能调原生能力）
# ============================================================

## 三、关键原生配置

### 1. AndroidManifest.xml
路径：`apk/agent-app/android/app/src/main/AndroidManifest.xml`

在 `<manifest>` 内、`<application>` 外添加权限：

```xml
<uses-permission android:name="android.permission.INTERNET"/>
<uses-permission android:name="android.permission.ACCESS_NETWORK_STATE"/>
<uses-permission android:name="android.permission.FOREGROUND_SERVICE"/>
<uses-permission android:name="android.permission.FOREGROUND_SERVICE_DATA_SYNC"/>
<uses-permission android:name="android.permission.POST_NOTIFICATIONS"/>
<uses-permission android:name="android.permission.RECEIVE_BOOT_COMPLETED"/>
<uses-permission android:name="android.permission.WAKE_LOCK"/>
<uses-permission android:name="android.permission.REQUEST_IGNORE_BATTERY_OPTIMIZATIONS"/>
<!-- 用于读取本机电量并上报 -->
<uses-permission android:name="android.permission.BATTERY_STATS" tools:ignore="ProtectedPermissions"/>
```

在 `<application>` 内添加服务声明：

```xml
<service
    android:name=".AgentService"
    android:enabled="true"
    android:exported="false"
    android:foregroundServiceType="dataSync"/>

<receiver
    android:name=".BootReceiver"
    android:enabled="true"
    android:exported="true">
    <intent-filter>
        <action android:name="android.intent.action.BOOT_COMPLETED"/>
    </intent-filter>
</receiver>
```

### 2. 允许明文 HTTP（访问本机 Prism :8080）
`android/app/src/main/res/xml/network_security_config.xml`（新建）：

```xml
<?xml version="1.0" encoding="utf-8"?>
<network-security-config>
    <!-- 只对本机放行明文，外部一律走 HTTPS -->
    <domain-config cleartextTrafficPermitted="true">
        <domain includeSubdomains="false">127.0.0.1</domain>
        <domain includeSubdomains="false">localhost</domain>
    </domain-config>
</network-security-config>
```

在 `<application>` 里引用：
```xml
android:networkSecurityConfig="@xml/network_security_config"
android:usesCleartextTraffic="false"
```

### 3. 前台服务（核心，保证不掉线）
`android/app/src/main/java/com/prism/agent/AgentService.java`：

```java
package com.prism.agent;

import android.app.Notification;
import android.app.NotificationChannel;
import android.app.NotificationManager;
import android.app.Service;
import android.content.Intent;
import android.os.Build;
import android.os.IBinder;
import androidx.core.app.NotificationCompat;

public class AgentService extends Service {
    private static final String CHAN = "prism_agent";
    private static final int NID = 1001;

    @Override public void onCreate() {
        super.onCreate();
        createChannel();
        Notification n = new NotificationCompat.Builder(this, CHAN)
            .setContentTitle("Prism 被控端运行中")
            .setContentText("正在等待云端指令")
            .setSmallIcon(android.R.drawable.stat_sys_upload)
            .setOngoing(true)
            .setPriority(NotificationCompat.PRIORITY_LOW)
            .build();
        if (Build.VERSION.SDK_INT >= 29) {
            startForeground(NID, n,
                android.content.pm.ServiceInfo.FOREGROUND_SERVICE_TYPE_DATA_SYNC);
        } else {
            startForeground(NID, n);
        }
        // 这里启动实际的轮询线程（见 AgentLoop.java）
        AgentLoop.start(getApplicationContext());
    }

    @Override public int onStartCommand(Intent i, int flags, int startId) {
        return START_STICKY;   // ★ 被杀后自动重启
    }

    @Override public IBinder onBind(Intent i) { return null; }

    private void createChannel() {
        if (Build.VERSION.SDK_INT >= 26) {
            NotificationManager m = getSystemService(NotificationManager.class);
            NotificationChannel c = new NotificationChannel(
                CHAN, "Prism 被控端", NotificationManager.IMPORTANCE_LOW);
            m.createNotificationChannel(c);
        }
    }
}
```

### 4. 开机自启
`android/app/src/main/java/com/prism/agent/BootReceiver.java`：

```java
package com.prism.agent;

import android.content.BroadcastReceiver;
import android.content.Context;
import android.content.Intent;
import android.os.Build;

public class BootReceiver extends BroadcastReceiver {
    @Override public void onReceive(Context ctx, Intent intent) {
        if (Intent.ACTION_BOOT_COMPLETED.equals(intent.getAction())) {
            Intent svc = new Intent(ctx, AgentService.class);
            if (Build.VERSION.SDK_INT >= 26) ctx.startForegroundService(svc);
            else ctx.startService(svc);
        }
    }
}
```

## 四、执行引擎（AgentLoop）

`AgentLoop.java` 的核心逻辑与 `agent/prism_agent.py` 一一对应：

| Python 版 | Android 版 |
|-----------|-----------|
| `do_register()` | `Http.post("/api/v1/device/register")` |
| `send_heartbeat()` | 每 20 秒一次，带 `X-Device-Id/Token` |
| `cloud("/api/v1/device/poll")` | 长轮询 25 秒 |
| `chat_stream()` | `HttpURLConnection` 读 SSE 流 |
| `report()` | POST `/api/v1/device/report` |

**推荐做法**：不要用 Java 重写全部逻辑。用 Capacitor 的 WebView 直接跑
`agent/prism_agent.py` 的等价 JS 版本（见 `apk/agent-app/www/agent.js`），
原生层只负责：
1. 拉起前台服务保活
2. 提供电量/型号等设备信息给 JS
3. 开机自启

这样跨平台、好维护。

### 设备信息桥接（Capacitor 插件）
```javascript
// www/agent.js 里
import { registerPlugin } from '@capacitor/core';
const DeviceInfo = registerPlugin('DeviceInfo');

async function collectMeta(){
  try{
    const d = await DeviceInfo.get();
    return {
      platform: 'android',
      model: d.model || '',
      android_ver: d.osVersion || '',
      battery: d.battery ?? -1,
    };
  }catch(e){
    return { platform:'android', model:'', android_ver:'', battery:-1 };
  }
}
```

## 六、安装到云手机

```bash
# 方式 1：adb 安装
adb connect <云手机IP>:<端口>
adb install -r app-debug.apk

# 方式 2：在云手机里直接点 APK 文件安装
```

### 安装后必做的三件事

1. **授予通知权限**（Android 13+）—— 没有它前台服务起不来
2. **关闭电池优化**：
   设置 → 应用 → Prism 被控端 → 电池 → 无限制
3. **允许自启动**：
   设置 → 应用 → 自启动管理 → 允许
   （国产 ROM 各家叫法不同，红手指/多多云这类云手机通常有专门的
   「后台保活」开关，务必打开）

## 七、常见问题

**Q: App 装上了但设备不在列表里**
- 检查网关地址末尾没有多余斜杠
- 检查密钥是否正确（填错会 401）
- 云手机能不能访问外网？试着用浏览器打开网关的 `/health`

**Q: 一直显示离线**
- 前台服务被系统杀了。去设置里关闭电池优化、开启自启动
- 云手机平台的「后台保活」没开

**Q: Prism 显示未运行**
- 云手机上 Prism 工具箱没启动
- 或者端口不是 8080（App 里可改）

**Q: 抓不到包**
- 机器人必须先连上服务器，否则没有流量
- 在控制台「信息」页看「机器人已连服」是否为「是」
