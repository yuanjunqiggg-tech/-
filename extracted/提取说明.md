### 5.1 现在我们能做什么

| 能力 | 实现方式 |

### 5.2 提示词替换的两种粒度

**粒度 A：只换提示词**
```python
body['messages'][0]['content'] = 你的提示词
```

**粒度 B：换提示词 + 换工具集**（更强）
```python
body['messages'][0]['content'] = 你的提示词
body['tools'] = 你自定义的工具列表  # 可增删改
```

比如你可以**移除 `system_shell` 工具**（安全考虑），
或**加入你自己的工具**。

## 六、捕获代理的工作方式

```
Prism ──POST──> 捕获代理(:8787) ──转发──> prism.adblanlu.qzz.io
                      │
                      ├─ 保存完整请求到 captured_prompts/
                      ├─ 可改写 system prompt
                      └─ 可改写 tools 数组
```

### 启用步骤

1. 启动代理：
   ```bash
   python tools/capture_proxy.py
   ```

2. 在 Prism「模型设置」里：
   - 新建一个模型，BaseURL 填 `http://127.0.0.1:8787`
   - 或直接用 API 添加（我们已验证可行）：
     ```bash
     curl --noproxy '*' -X POST http://127.0.0.1:8080/api/ai/models \
       -H "Content-Type: application/json" \
       -d '{"name":"捕获代理","base_url":"http://127.0.0.1:8787",
            "api_key":"x","model_id":"auto","provider":"openai","streaming":true}'
     ```

3. 在「AI 帮写」里选中这个模型发消息 → 自动捕获

> ✅ **已验证**：上述 API 添加模型成功，捕获到 29KB 完整请求。
